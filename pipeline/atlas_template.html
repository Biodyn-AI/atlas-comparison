A comparative atlas of ten single-cell foundation models

Ten models were run on the same 6,000 Tabula Sapiens cells and their internal states split into interpretable features with one method. The atlas shows what each model encodes, what they share, which to use for a given task, and how each result compares with chance and with plain co-expression from the same cells.

What a model does

What a single-cell foundation model does

A cell goes in as a list of gene activities. A vector of numbers comes out. Everything useful — and everything this atlas measures — happens in between.

In
One cell About 20,000 genes, each with a number: how many RNA copies were read. Most are zero.
ACTB 812 · B2M 604 · CD3E 41 · INS 0 · …
Each model reads that list its own way:
  • rank order only — which genes are highest, not by how much: Geneformer-V2, tGPT, MaxToki, and C2S-Scale, which reads the ranked gene names as a sentence with a language model
  • rank order plus the value: GeneCompass
  • the expression value: scGPT, AIDO.Cell, scFoundation, Tahoe-x1
  • the protein each gene encodes (an ESM embedding), genes drawn in proportion to their expression: UCE
→
Model
A transformer, 8–33 layers, 10 M to 3 B parameters Trained on millions of cells to fill in hidden genes or to predict the next one. Seven of the ten see nothing but the counts; three carry outside knowledge: UCE reads each gene as its protein (ESM2), GeneCompass is given regulatory networks, gene families and promoters, and C2S-Scale starts from a language model trained on text.

Every layer keeps a vector for each gene in the cell (some models add one for the cell itself). Those vectors are the internal state this atlas opens up, layer by layer.

→
Out
Vectors, not biology
  • a cell embedding — which cells are alike: cell typing, joining datasets
  • gene embeddings — which genes behave alike: networks, function
  • predictions — the hidden genes, or how a cell responds to a perturbation

Someone still has to read those vectors. That is what interpretability is for, and why the atlas splits them into features.

About

What this atlas is

Ten models were shown the same 6,000 cells. We split each model's internal state into interpretable features, test each feature against known biology, and compare all ten. The pipeline:

A cellwhich genes are switched on
An AI model reads itlayer by layer
Its internal statea big vector of numbers
We split it into featuressparse & interpretable (an “SAE”)
immunecell cycletranslation
Some features = a programmea known piece of biology; most stay unlabelled
…and we run this for all 10 models on the same cells with the same recipe. The remaining differences (adapters, what counts as the first layer, positions per cell) are listed under Models and methods.
Feature
one interpretable unit the SAE pulls out of a model — it switches on for a specific pattern of genes. A single layer has a few thousand.
Concept
a known piece of biology — a GO / Reactome / KEGG pathway or a STRING protein-interaction set. One feature can match none, one, or several. Not all matches are equal: broad PPI/large sets are easy to hit by chance; specific small pathways carry more signal.
Module
a group of features that fire together across cells — a community, not a single feature. This is the network view under Findings → Modules.
Annotation
how a feature earns its concepts: take its top genes → test (Fisher exact, BH<0.05) whether they overlap a known gene set more than chance → the sets that pass become its concepts. The permissive default (top-5 vs huge overlapping databases) over-fires — even random genes pass — so a calibrated version (top-10, ≥3 in a curated ≤200-gene set, no PPI) is used to test real sharing (see Controls).
How far to trust the “shared core”: under the permissive rule, 1,977 concepts are shared by all 10 models, but random genes give a larger shared set, so that count is an artefact of the rule. Under the strict rule, 96 concepts are shared by at least 8 of the 10 models (27.5× what random genes give) — translation, ER targeting, mRNA decay, antigen presentation. The core is real but modest: co-expression gene groups from the same cells, with no model, give a core that holds 89 of the 96. See Findings and their baselines.
Colour guide: in bar & line charts each model has its own fixed colour; in the network maps colour is a keyword theme of the module's permissive label (a hint, the same on every layer).
Chapter 2

The shared core

Do ten very different models learn the same biology?

Backbone

The shared backbone

Count how many of the ten models encode each concept. The raw count is inflated by large, overlapping databases; under the strict test, 96 concepts are encoded by at least 8 of the 10 models. That is the backbone.

What the backbone is good for
If your question lives in the backbone — translation, ER targeting, mRNA decay, MHC-II antigen presentation, cytokine signalling, muscle contraction — at least eight of the ten models encode it (no concept is in all ten). It is shared and reproducible, but largely what co-expression from the same cells gives: co-expression gene groups, with no model, give a core that holds 89 of the 96. MaxToki lacks the protein-synthesis sets at the middle layer.
If it does not, few models encode it under the strict rule. Use gene search to see which models carry features for your genes. Per-model concept lists repeat unevenly on a second draw of cells (Jaccard 0.025–0.812 by model), so treat them as leads.
For interpretability work, the core depends on training: SAEs that were never trained give a core of 36 instead of 96, and only 4 of the 36 are protein synthesis. It is still mostly basic cell machinery.

Linearity

Linear representation of the biology

Superposition says features are non-orthogonal directions — but are the concepts they carry read out linearly? We decode a concept from each model's per-cell embeddings with a linear probe and a nonlinear MLP. If the MLP gains nothing over the linear probe, the concept can be read out linearly. This is weak evidence: a linear readout of the raw counts' principal components reads tissue about as well (0.942). Bars normalised to chance → 100%.

Known pairs

Known regulatory pairs

Plain co-expression from the same cells does about as well. Genes that repeatedly share a feature form predicted pairs; we count how many are known TF–target pairs in TRRUST and compare with rewired networks that keep every gene's number of partners, and with co-expression networks matched to each model. TRRUST was not used to train the SAEs or to build the pairs, but the threshold of five features was chosen after several thresholds had been scored on TRRUST.

Controls

Controls and robustness

Checks of the main results against chance baselines. The strict-rule tests and the summary are below; checks made with the permissive rule are grouped under “Loose-rule checks (illustrative)”.

Is the shared core real, or just ubiquitous sets?
The universal core vs a size-weighted permutation null (each model keeps its concept count, but draws random sets weighted by gene-set size — so big, ubiquitous sets are expected to be hit). If the core were an artefact of "everything hits the ribosome", it would sit at the null.
Is it just "more layers = more chances"?
The core counted three ways: one mid layer, an equal number of layers for every model (8, evenly spaced — removes the UCE-33 vs AIDO-8 advantage), and all layers. If the all-layer core were a layer-count artefact, equal-layer would collapse back toward mid.
Is "number of concepts" a fair richness metric?
Correlation of a model's concept count with things that are not biology: SAE width (d_sae), number of layers, surfaced gene vocabulary. High = the metric partly measures capacity, not what the model learned.
Does the concentration axis hold up?
Three stress tests on the concentration↔breadth finding: link to tokenisation (raw and controlling for d_sae), link to SAE capacity, and leave-one-out on the Fisher↔GSEA anti-correlation (does one model carry it?).
Does one SAE seed decide the numbers?
The whole atlas is built on one SAE per model per layer, and SAE training is stochastic. We retrained the SAE on every layer with 3 seeds per model (from the same frozen-model activations — only the SAE varies) and re-ran the full annotation, then re-computed the all-layer universal core per seed.
Further loose-rule checks
Ontology redundancy in the core, the SVD-alignment count against random directions, and blind spots corrected for gene vocabulary.
Does the shared core repeat on a second draw of cells?
Every model is re-extracted on a second draw of 5,581 cells from the same tissues and data release, none of them in the first draw; the core is rebuilt and compared with the first on the same models & layers. The baseline is weak: same tissues, same data release, and settings chosen on the first draw.
Is the annotation itself calibrated? (and residual limits)
The hardest self-check: replace every feature's top genes with random background genes and re-run the annotator. If a feature's rate of getting any label barely changes, then "annotation rate" is measuring database density, not the feature's specificity.
The shared core under the strict rule
A strict rule chosen over a grid of databases (no PPI), set size, minimum overlap and odds ratio, so that random genes rarely get a label; then the real cross-model core is compared with the random-gene baseline. The strict rule's settings were chosen on the first draw of cells, and how far the core beats chance depends on them.

How to use

How to use the atlas

Each with a worked example. Every number is read from the atlas, and each button does what it says.

Methods

Models and methods

Ten models, one 6,000-cell Tabula Sapiens corpus (immune, kidney, lung), a TopK SAE (k = 32, 4× width) on every layer. Two annotation rules: the permissive rule (random genes pass it almost as often as real features; used only for illustrative per-model panels) and the strict rule (top-10 genes, ≥3 in a curated ≤200-gene set, no PPI), used for the shared core, the labelled shares and the chooser. Some panels still use the permissive rule and say so.

Settings
Three Tabula Sapiens compartments (immune, kidney, lung) · layers at 0/25/50/75/100 % depth for the depth-matched views, every layer elsewhere · UCE at 650M · all ten models, including Tahoe-x1 3B, extracted on one shared pipeline. The permissive rule's settings are top-5 genes and 5 databases including STRING protein interactions; they are kept for the per-model descriptions. The strict rule uses top-10 genes, ≥3 in a curated ≤200-gene GO/Reactome/KEGG set, no PPI. Differences between models that remain: each model's adapter (the script that turns counts into its input); what counts as the first layer (the input embedding in AIDO.Cell, tGPT and GeneCompass); at most 168 gene positions kept per cell (64 genes per cell in tGPT); and, with k = 32 and dictionaries of 1,024 to 10,240 features, a tenfold range in the share of active features.
Considered but out of scope
The atlas needs per-cell, gene-token foundation models with an accessible residual stream, so the same TopK-SAE can be trained on the same representation across every model. Two prominent recent models fall outside that frame — both are perturbation-response predictors that operate on cell sets, not per-cell representations, so there is no directly comparable residual to decompose:
· State (Arc Institute) — State-Transition predicts post-perturbation expression, State-Embedding embeds cells at the set level; it models how cell sets respond to perturbations.
· X-Cell (Xaira Therapeutics) — a set-level diffusion transformer for genome-scale perturbation responses; additionally, its weights are not yet public ("coming soon") and it is non-commercially licensed.
Both belong in a perturbation atlas, not this representation atlas.
