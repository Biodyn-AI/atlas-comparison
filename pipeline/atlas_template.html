What this atlas is, in one picture

Ten AI “foundation models” were each shown the same cells. We open every model up, split its internal thinking into small interpretable features, and match each feature to known biology — then compare all ten. The pipeline:

A cellwhich genes are switched on
An AI model reads itlayer by layer

We split it into featuressparse & interpretable (an “SAE”)
immunecell cycletranslation
Each feature = a programa known piece of biology
…and we run this for all 10 models on the same cells, so every difference we see is the model, not the data.
Four words you need
Feature
one interpretable unit the SAE pulls out of a model — it switches on for a specific pattern of genes. A single layer has a few thousand.
Concept
a known piece of biology — a GO / Reactome / KEGG pathway or a STRING protein-interaction set. One feature can match none, one, or several. Not all matches are equal: broad PPI/large sets are easy to hit by chance; specific small pathways carry more signal.
Module
a group of features that fire together across cells — a community, not a single feature. This is the network view in “Explore”.
Annotation
how a feature earns its concepts: take its top genes → test (Fisher exact, BH<0.05) whether they overlap a known gene set more than chance → the sets that pass become its concepts. The permissive default (top-5 vs huge overlapping databases) over-fires — even random genes pass — so a calibrated version (top-10, ≥3 in a curated ≤200-gene set, no PPI) is used to test real sharing (see Controls).
How far to trust the “shared core”: a big raw core (2,267 concepts in all 10 models) turned out to be an artefact of the permissive annotation — it doesn't beat a random-gene null. The calibrated result is a shared backbone of ~78 concepts across ≥8 of the 10 models (~20× over that null) — translation, ER targeting, mRNA decay, antigen presentation — plus each model's own biology. The full audit is in Controls.
Colour guide: in bar & line charts each model has its own fixed colour; in the network maps colour instead = the biological theme (same on every layer).

The finding
Why you need this atlas at all

Almost every feature is missed by a linear (PCA) summary

The usual way to compress a model’s internal state is PCA/SVD — keep a few dominant “principal directions”. We check how many of the SAE features actually line up with those directions. Almost none do (~100% miss), so the real structure is invisible to the classic method — you need the feature dictionary (SAE) to see it at all. This reproduces the known result across all 10 models.

Is the biology linearly represented

Superposition says features are non-orthogonal directions — but are the concepts they carry read out linearly? We decode a concept from each model's per-cell embeddings with a linear probe and a nonlinear MLP. If the MLP gains nothing over the linear probe, the concept lives on a linear direction — the assumption the whole SAE approach rests on. Bars normalised to chance → 100%.

Controls & robustness

We tested our own headline claims against null models. Some hold up; others turn out to be confounded. Both are reported below.

Is the shared core real, or just ubiquitous sets?
The universal core vs a size-weighted permutation null (each model keeps its concept count, but draws random sets weighted by gene-set size — so big, ubiquitous sets are expected to be hit). If the core were an artefact of "everything hits the ribosome", it would sit at the null.
Is it just "more layers = more chances"?
The core counted three ways: one mid layer, an equal number of layers for every model (8, evenly spaced — removes the UCE-33 vs AIDO-8 advantage), and all layers. If the all-layer core were a layer-count artefact, equal-layer would collapse back toward mid.
Is "number of concepts" a fair richness metric?
Correlation of a model's concept count with things that are not biology: SAE width (d_sae), number of layers, surfaced gene vocabulary. High = the metric partly measures capacity, not what the model learned.
Does the concentration axis hold up?
Three stress tests on the concentration↔breadth finding: link to tokenisation (raw and controlling for d_sae), link to SAE capacity, and leave-one-out on the Fisher↔GSEA anti-correlation (does one model carry it?).
Does one SAE seed decide the numbers?
The whole atlas is built on one SAE per model per layer, and SAE training is stochastic. We retrained the SAE on every layer with 3 seeds per model (from the same frozen-model activations — only the SAE varies) and re-ran the full annotation, then re-computed the all-layer universal core per seed.
Round 2 — harder nulls (and where they bite)
A second reviewer pass, including checks on the checks: ontology redundancy in the core, the superposition metric against a random-direction null, vocabulary-corrected blind spots, and a confidence interval on the scaling law.
Does the shared core replicate on new cells? (held-out)
The strongest external check: re-extract every model on an independent 6,000-cell sample (a second Tabula Sapiens draw, same tissues, no overlap), rebuild the universal core, and compare to the original on the same models & layers. If the core were an artefact of the specific cells, it would not come back.
Is the annotation itself calibrated? (and residual limits)
The hardest self-check: replace every feature's top genes with random background genes and re-run the annotator. If a feature's rate of getting any label barely changes, then "annotation rate" is measuring database density, not the feature's specificity.
Can a calibrated annotator rebuild the core?
If the permissive annotator inflates the core, does a stricter, calibrated one recover a real signal? We grid over databases (drop PPI), set size, min-overlap and odds-ratio until random genes almost never annotate, then check whether the real cross-model core still beats the random-gene null. The annotator config is fixed on this (discovery) corpus before the held-out test — held-out never informs the choice, so it is an independent validation, not selection.

The atlas · methods

Seven models, one corpus, one depth rule, one annotator

Every model re-extracted on the same 6,000-cell Tabula Sapiens corpus (immune + kidney + lung, raw counts); TopK SAE (k=32, d=4×) on the residual at five matched relative depths; top-5 decoder genes; one annotator (Fisher 'greater' + BH<0.05 vs GO_BP/Reactome/KEGG and TRRUST). The comparison at the matched 50%-depth layer.

Design decisions
All three Tabula Sapiens tissues ✓ · depth-matched 0/25/50/75/100% ✓ · top-5 genes (empirically sharper than top-20: median odds-ratio ~1.5× higher, no saturation) ✓ · 5 databases incl STRING PPI edges ✓ · UCE at 650M ✓ · all ten models re-extracted on one shared pipeline ✓. Every model shown — including Tahoe-x1 3B — is fully extracted; scPRINT (ESM-augmented) is the one intended addition still pending a cluster-side fix, and slots in without changing the pipeline.
Considered but out of scope
The atlas needs per-cell, gene-token foundation models with an accessible residual stream, so the same TopK-SAE can be trained on the same representation across every model. Two prominent recent models fall outside that frame — both are perturbation-response predictors that operate on cell sets, not per-cell representations, so there is no directly comparable residual to decompose:
· State (Arc Institute) — State-Transition predicts post-perturbation expression, State-Embedding embeds cells at the set level; it models how cell sets respond to perturbations.
· X-Cell (Xaira Therapeutics) — a set-level diffusion transformer for genome-scale perturbation responses; additionally, its weights are not yet public ("coming soon") and it is non-commercially licensed.
Both belong in a perturbation atlas, not this representation atlas.
